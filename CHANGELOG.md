# Изменения

## v1.0.1

- В списке файлов SD свежие записи отображаются сверху: сортировка по имени в обратном порядке.
- Добавлен фильтр по имени файла без дополнительных запросов к ESP. Фильтр сохраняется при обновлении списка.
- Изменения только в интерфейсе; HTTP API и прошивка не менялись.

## v1.0.0

- Windows-релизы x86/x64, выбор версии и обновление из программы с проверкой SHA-256 и сохранением настроек.
- GitHub Actions на Node.js 24, тесты и проверка собранного updater перед публикацией.
- Удалено локальное хранилище АЦП и HDF5; сохранены запись на SD и экспорт термостата.
